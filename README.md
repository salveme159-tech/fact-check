# DART 기사 팩트 체크 (전용 버전)

기사 원문을 붙여 넣으면 **기업명·날짜/기간·금액·퍼센트·부호**를 수치마다 따로 인식해 OpenDART 공시값과 대조합니다.
기사 팩트 체크 외의 기능(공시 질의·재무 비교·알람·PDF/엑셀·ChatGPT 에이전트·로그인 등)은 모두 제거했습니다.

## 무엇을 구별하는가

| 구분 | 방식 |
|---|---|
| 기업 | 수치마다 소유 기업을 지정. 같은 문장에서 직접 언급된 기업 / 앞 문장에서 이어받은 기업(다기업 기사에서 경고 표시)을 구분. `LS전선(2조원)` 괄호 수치, `A와 B는 각각 X, Y` 병렬 서술, `LS전선보다·대비` 비교 대상(주어 아님) 처리 |
| 날짜·기간 | 연도·분기·상반기·누계/당분기·연결/별도를 수치마다 해석하고, `지난해→2025년` 같은 해석 근거를 표시. 원문의 날짜 표현은 파란 점선으로 따로 표시 |
| 수치 | 조·억·만·원 단위를 억원으로 통일, 표기 자릿수 반올림 범위까지 일치 판정 |
| 부호 | `-`, `−`, `△`, 영업손실·적자·순유출(음수), 흑자·순유입(양수)을 반영. 숫자 사이 하이픈(`3-4%`)은 부호로 보지 않음. 증감률은 증가(+)/감소(−) 방향으로 별도 판정 |

## 판정

- **일치**: 표기 자릿수 반올림 범위(‘약’은 0.5%)에서 공시값과 같음
- **불일치**: 유형을 함께 표시 — 부호 반대 / 부호·크기 모두 다름 / 자릿수(단위) 오류 의심(10·100·1,000·10,000배) / 증감 방향 반대 / 수치 차이
- **확인 필요**: 기업·기간 미확정, 전망·목표, 변동액(‘2,000억원 감소’), 총사업비·누적 수주, 지원하지 않는 수치 등 — 틀렸다고 단정하지 않음

## 실행

```bash
pnpm install
pnpm test                # 회귀 테스트 72건 (DART 응답 fixture 사용)
pnpm dev                 # 서버 :3000
pnpm dev:client          # 화면 :5173 (/api는 서버로 프록시)
pnpm build && pnpm start # 서버+화면 한 곳에서 서비스 (Docker/Render: VITE_BASE=/)
```

OpenDART 인증키는 화면 상단에 입력합니다(브라우저에만 저장, 조회 때 서버로 전달). 서버 환경변수 `OPENDART_API_KEY`는 선택입니다.

GitHub Pages로 화면만 배포할 때는 저장소 Variables에 `VITE_API_BASE_URL`(서버 주소)을 등록하고, 서버의 `CORS_ALLOWED_ORIGINS`에 Pages 주소를 넣으세요. 팩트 체크는 서버 API(`dart.articleFactCheck`)가 필요하므로 서버 배포는 필수입니다.
